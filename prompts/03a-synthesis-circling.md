# Prompt 03a: What I keep circling

**Use case**: You've been working all week. You feel busy. But some topics you keep returning to without ever deciding. This prompt finds them. The output is uncomfortable in a useful way.

**When to run**: Sunday, item 3 of the weekly review. Pick this prompt when you suspect you've been spinning instead of shipping.

## The prompt

```
Synthesis: Look at my last 7 days of chats with you. What topics have I been circling without committing to? What's the recurring friction I keep solving the same way instead of fixing once?

For each topic, give me:
1. The pattern (what I keep doing)
2. The decision I'm avoiding (the thing I'd have to commit to in order to stop circling)
3. The cost of continuing to circle (what happens if I don't decide this week)

Be direct. I want the version of this answer that a co-founder would give me over coffee, not the diplomatic version.
```

## How to use the output

1. Read it slowly. Don't skim.
2. Pick ONE topic. Not all of them. The one that hit hardest.
3. Open a note. Write: "This week I will commit to: [the decision]."
4. Put the decision on your calendar as a 30-minute block within the next 48 hours.

The whole prompt is wasted if you don't act on the output. The point isn't to know what you're circling. The point is to stop.

## Customize

If you want it less direct (some weeks the gentle version is more useful):

```
Replace "Be direct" with "Be gentle but honest. I'm tired this week."
```

If you want a longer time window:

```
Replace "last 7 days" with "last 30 days." You'll see the deeper patterns that don't show up in a week.
```

## Pairs with

Item 4 (clean your context files). Sometimes the thing you're circling is in your `me.md` as a goal you've outgrown. The synthesis surfaces it; the context-file cleanup retires it.
