# Prompt 03b: Pattern detection

**Use case**: You think you know how you spent the week. The chats know better. This prompt surfaces the gap between where the time went and where you thought it went.

**When to run**: Sunday, item 3 of the weekly review. Pick this prompt when you want to optimize your week, not just reflect on it.

## The prompt

```
Pattern detection: Across my last week of chats with you, where did I spend the most time? Where did I make the most progress? Where's the gap between those two answers, and what does that gap suggest about what I should change next week?

Structure your answer as:
1. Where the time went (top 3 topics by chat volume)
2. Where the progress happened (top 3 topics by actual output / decision / shipped thing)
3. The gap (topics where I spent a lot of time but didn't move forward)
4. One concrete change for next week that closes the gap
```

## How to use the output

1. Look at the gap section. That's where the leak is.
2. The "one concrete change" is your move for next week. Write it down.
3. Don't try to fix multiple things at once. One change per week. The compounding only works if you actually run the change.

## Customize

If you have specific projects you want measured against:

```
Add at the end: Pay special attention to [project name 1] and [project name 2]. I want to see how much of my week actually went to those compared to other things.
```

This is useful when you have a stated priority that you suspect you're not actually working on.

## Pairs with

Item 5 (plan one new slash command). If pattern detection shows you spending a lot of time on something repetitive, the slash command prompt (05) is how you build the automation that removes it next week.
