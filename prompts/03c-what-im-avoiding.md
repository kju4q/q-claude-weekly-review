# Prompt 03c: What I'm avoiding

**Use case**: Some weeks the most important question is the one you didn't ask. This prompt finds it.

**When to run**: Sunday, item 3 of the weekly review. Pick this prompt when you have a sense something's off but can't name it.

## The prompt

```
What I'm avoiding: Look at the questions I've asked you this week. What hard question have I been avoiding asking? What would happen if I asked it now?

Format your answer as:
1. The question I've been avoiding (one sentence, direct)
2. The evidence (which chats hint at this question without ever asking it directly)
3. The reason I'm probably avoiding it (the discomfort that's at the bottom of the avoidance)
4. The version of the question I should ask you right now to actually face it

Don't soften this. I asked for it because I'm ready to hear it.
```

## How to use the output

1. Read the question. Sit with it for 60 seconds before doing anything.
2. Run the version of the question Claude suggests at step 4.
3. Treat that follow-up chat as the real session. Whatever came before was the warmup.

The output of THIS prompt is rarely the answer. The output is the question you should have been asking all week. Asking it is the move.

## Customize

If you want a softer version (some weeks the raw version is too much):

```
Add: Be honest but kind. I want the truth, not the lecture.
```

If you're avoiding something specific you can name but can't face:

```
Replace the first paragraph with: I have a sense I'm avoiding [the thing]. Confirm or correct: am I avoiding this, or am I avoiding something deeper that this is a proxy for?
```

## Pairs with

Item 1 (update your me.md). Sometimes what you're avoiding is updating `me.md` because the update would force you to face that you've outgrown the version of yourself in the file. Update it.

## When NOT to run this prompt

Some weeks you don't have the emotional energy to face a hard question. Skip this one and run 03a or 03b instead. The synthesis layer is more useful when you can actually do something with the output.
