# Your Claude Weekly Review

A 15-minute ritual you run every Sunday so next week's Claude starts smarter than this week's did.

> The difference between using Claude and having an AI co-founder is whether you maintain your context or not. This is the maintenance.

## What's in this repo

| File | What it is |
|------|------------|
| [`CHECKLIST.md`](CHECKLIST.md) | The full 5-item Sunday review. Start here. |
| [`FIRST_TIME.md`](FIRST_TIME.md) | Modified version for your very first run. Skip a few items, do a few differently. |
| [`prompts/`](prompts/) | Each prompt as a standalone file you can copy-paste cleanly. One file per checklist item. |
| [`GOING_DEEPER.md`](GOING_DEEPER.md) | The full q-os ecosystem. Repos for Projects, artifacts, Claude Code setup, and the synthesis prompt library. |

## Who this is for

You use Claude regularly. You've felt the gap between "Claude knows what I'm working on this morning" and "Claude has forgotten everything by Friday." You don't want to keep retyping the same context. You want compounding instead.

This checklist is the smallest weekly ritual that closes that gap. 15 minutes. You run it on Sunday so Monday morning's Claude is already up to date.

## How to start

1. Read [`CHECKLIST.md`](CHECKLIST.md). That's the main artifact.
2. If this is your first run, also read [`FIRST_TIME.md`](FIRST_TIME.md) before you start. The first run is different.
3. Open Claude. Open the [`prompts/`](prompts/) folder in another tab so you can grab each prompt as you go.
4. Work through the 5 items in one Claude session. Total time: 15 minutes after you've done it 2-3 times.
5. Put it on your calendar. Sunday, recurring. The habit IS the system.

## After a month

You run this every Sunday for 4 weeks. Your `me.md` becomes accurate. Your sidebar has 3-4 active Projects instead of 12. You've shipped 1-2 changes to how you work based on the synthesis prompts. Your context files are clean and current. You have 2-3 personal slash commands you use multiple times a week.

None of these are dramatic individually. The compounding is.
